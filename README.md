# Data Quality Validator

CSVデータの品質を検査するPythonツールです。

自治体システムのデータ移行・品質検証で得た知見をもとに、
個人情報を含まない架空データを使用して作成します。

## 検査予定の項目

- 必須項目の空欄
- 主キーの空欄
- 主キーの重複
- 日付の妥当性
- 数値項目の形式
- 最大文字数

## 使用技術

- Python 3.11
- pandas
- pytest
- GitHub Actions

## 注意事項

このリポジトリで使用するデータ、テーブル名、仕様はすべてサンプルです。
実際の自治体名、業務データ、個人情報は含みません。
